# Quantitative Measures of Collective Memory

Collective memory in teams can be quantified through Transactive Memory Systems (TMS), which correlate with team performance over time.

## Findings

Empirical studies, including longitudinal analyses, establish that effective Transactive Memory Systems—where team members know who knows what—are a primary indicator of collective memory [source-33a17dc3cd5a4168]. Quantitative performance metrics in these studies rely on the stability and accuracy of information retrieval within the team network [source-0da21a56c51e4b71]. Our synthesis indicates that memory formation is not merely static retention but a dynamic, verifiable mapping of internal expertise that directly influences team output reliability.

## Limitations and competing views

Most longitudinal data focuses on established corporate or academic teams; it remains unclear if these metrics translate to non-hierarchical, decentralized, or digital-only networks.

## Next questions

Can these TMS metrics be applied to decentralized digital networks? How does attention filtering (the second factor) influence the quality of TMS formation?
